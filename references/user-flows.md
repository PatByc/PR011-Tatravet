# User flows

1. Open the shared dashboard link, sign in with clinic credentials, review today's calls and outstanding callbacks.
2. Open a call, read its transcript/summary, set follow-up status and add a note. Save; conflicting edits require reopening instead of silent overwrite.
3. Search call history by number/transcript; filter dates, call state or follow-up. The callback queue covers all dates.
4. Inspect daily/hourly analytics for a chosen period in Warsaw time.
5. Copy the panel URL to a colleague; they still need clinic credentials.
6. Change password in Settings to invalidate all sessions, or request operator recovery if forgotten.

Missing call artifacts display unavailable/processing text. Authentication failures, database errors and delayed synchronization are explicit. Demo calls are always labelled and never appear in the production dataset.
