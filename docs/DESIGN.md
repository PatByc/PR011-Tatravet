# Tatravet interface direction

Skill: `/home/orion/.codex/skills/frontend-design/SKILL.md`.

A quiet veterinary reception workspace: put calls requiring human attention first. Left-align content; use a persistent navigation column, a restrained statistics strip, and an asymmetric working area. The callback queue is the main distinctive element, paired with the hourly call chart. Tables provide a compact chronology, and a side drawer preserves context while staff reads a transcript.

Palette, derived from tatravet.pl's Elementor stylesheet: brand green #58AC27, secondary #7FB715, pale green #F1FEE9, white #FFFFFF, charcoal #333333. Dark green #32651B provides accessible buttons and text. Use self-hosted Poppins with Polish glyphs, 28px page headings, 15px section headings, 11–13px supporting/table text, and tabular numeric values.

Layout comparison: a chart-first reporting page would bury callback work. Choose the working queue first, and dedicate a separate tab to reporting.

```text
Navigation | Title / date filter
           | Four compact metrics in one strip
           | Callback queue | Calls by hour
           | Recent calls table
```

Review against brief: avoid a marketing hero or repeated decorative cards. The calm clinic identity comes from real brand colors and practical phone workflows. Use rounded surfaces for functional groups, not every label. Charts use color to encode quantities; no decorative animation. Interactive confirmation and reduced-motion support are required. Responsive tables scroll within their surface; mobile navigation remains visible near the top.
